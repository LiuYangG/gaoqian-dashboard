# 新增课节 / 新增学员

系统会尽量自动识别，通常不需要改代码。

## 新增一节课

1. 在课程资料目录放入课节目录，例如：
   `高潜授课/第一阶段/R1-P01-L06-一维数组与计数思想/教师版/01-教师教案.md`
2. 在 `config/sessions.json` 补一行（推荐，日期/作业名最准确）：
   ```json
   "L06": { "date": "2026-10-31", "homework": "山东高潜06", "title": "一维数组与计数思想" }
   ```
   不补也能运行：系统会按 `高潜06` 匹配作业，并从成绩表提交日期推断上课日。
3. 重新抽取蓝图并抓取：
   ```bash
   npm run blueprint
   npm run scrape
   ```
4. 提交 `blueprint/` 与 `config/` 的变更。GitHub Actions 每天 00:00（北京时间）会重新抓取并发布。

如果新课作业已经在 MarsOJ 出现、但课程资料还没放进来：不用等蓝图，抓取会自动把这次作业识别为「数据课次」，先按成绩表展示完成、一次通过和提交情况；补上蓝图后自动升级为完整课次。

## 新增一名学员

学员从成绩表自动读取，不需要手工加名单。

- 教师账号：把 UID 加到 `config/roles.json` 的 `teachers`。
- 尚未开始做题的新同学：系统会自动标记「未开始」，不计入班级均值和排名；一旦有提交会自动转为正常统计。
- 新增学员第一次出现后，下一次夜间抓取或手动 `npm run scrape` 就会纳入诊断。

## 口径

- 每节课的数据单独存放在 `data/raw/lessons/{课次}.json`，每次抓取覆盖旧文件并按记录 ID 去重。
- 抓取时间预算由 `RAW_BUDGET_MS` 控制（默认 10 分钟），每日增量只读检查点之后的新记录。
- 统计以 MarsOJ 每节课的实际题单题目为准；题单新增或调整后，下次抓取会自动按新题单统计。
